# b4moss/crudian (PHP)

Composer distribution mirror of [`b4moss/crudian`](https://github.com/b4moss/crudian) `packages/php`.

**Do not open PRs here.** Source of truth is the monorepo. This repository is updated by CD (`git subtree split`) so Packagist can consume a root-level `composer.json` and SemVer tags `vX.Y.Z`.

```bash
composer require b4moss/crudian
```
